# Generative AI Projects & Learning

A collection of hands-on projects exploring **Generative AI, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), Prompt Engineering, Image Captioning, Text Summarization, and Language Translation** using Python and Google Colab.

This repository documents my practical learning journey in AI and Generative AI, with individual Jupyter notebooks for experimenting with different concepts, models, and applications.

## 📂 Projects

| Project | Description |
|---|---|
| 🤖 **Chat Bot** | Explores building a conversational chatbot using Generative AI. |
| 🖼️ **Image Captioning** | Explores generating descriptive text captions from images using AI models. |
| ✍️ **Prompt Engineering** | Experiments with prompt design and techniques for improving the relevance and quality of AI-generated responses. |
| 📚 **Retrieval-Augmented Generation (RAG)** | Explores combining information retrieval with language models to generate context-aware responses. |
| 📄 **Document Summarization** | Explores summarizing documents into shorter, more manageable versions while retaining important information. |
| 🌐 **Language Translator** | Explores AI-powered translation from English to Urdu. |

## 🛠️ Technologies & Tools

- **Language:** Python
- **Environment:** Google Colab, Jupyter Notebook
- **Core Areas:** Generative AI, Large Language Models (LLMs), Prompt Engineering, RAG, Natural Language Processing (NLP), Image Captioning, Text Summarization, Machine Translation
- **Libraries & APIs:** Used as required by individual notebooks

## 🚀 Getting Started

You can explore the notebooks directly on GitHub or run them in Google Colab.

1. Open the notebook you want to explore from the project list.
2. Click **Open in Colab** if available, or download the `.ipynb` file and upload it to [Google Colab](https://colab.research.google.com/).
3. Install the dependencies specified in the notebook.
4. Configure any required API credentials using secure methods such as Google Colab Secrets.
5. Run the notebook cells in order and experiment with the code.

> **Note:** Some notebooks may require API keys, model downloads, external services, or additional dependencies. Check each notebook for its specific requirements.
